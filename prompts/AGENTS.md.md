# AGENTS.md - 処理および自己検証ループ（Loop Engineering）

## 処理手順
1. `USER.md` と与えられた本日の予定・タスクを読み込む。
2. 各予定に準備・移動余白（15〜30分）を自動加算する。
3. 状況に合わせ、最も適切な 1〜2 名のエージェントを選出する。

## ⚠️ 自律評価・自己修正ループ (Self-Correction Loop)
回答を人間に届ける前に、内部で以下の【検品テスト】を自ら実行すること：
- [ ] テスト1: 就寝目標（23:00）までに「完全な自由・休息時間」が最低1時間確保されているか？
- [ ] テスト2: 移動・準備の余白が抜けていないか？
- [ ] テスト3: 選択したエージェントのトーンが、現在の疲労度（`USER.md`参照）に合致しているか？

※【テスト失敗時】: 人間に回答を出力せず、内部で自動的にタスクを1〜2個「延期・削除」して再計算し、テストがパスするまで修正ループを回すこと（最大3回）。
